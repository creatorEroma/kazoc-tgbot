# Бот учёта заявок/сделок (рабочая сила)

Структура: **наша компания (KazOC)** → список **компаний-клиентов** (Алсер и т.д.)
→ внутри каждой компании создаются **конкретные дни-сделки (заявки)** со
статус-баром. Управление полностью кнопками. Без ИИ. База — SQLite.

## Возможности
- **Профиль компании-клиента:** название, телефон, адрес, контакт, заметки.
- **Заявка/сделка** (текущий или будущий период): город, дата, срок/время, часы,
  позиция, количество (план), тип работы, ставка, сколько платит клиент, сколько
  платят каждому работнику, сколько получает компания, ФИО работников на смене.
- **Статус-бар:** Принято → В работе → Удачная сделка / ❌ Неудачная. Виден в
  карточке заявки и в Excel-отчёте.
- **Завершение «Удачная сделка»** требует ввода: факт вышло работников + сумма оплаты.
- **Права:**
  - Руководителей может быть несколько. Видят всё, правят любые заявки, заходят
    в админку по паролю, могут назначать/снимать руководителей и менеджеров.
  - Менеджер видит только свои компании; **редактирует свои заявки только в день
    их создания** (потом блокируется; руководитель правит всегда).
- **Доступ:** только руководитель и менеджеры. Чужой видит «доступ запрещён» и свой ID.
- **Отчёты Excel:** за день (сегодня или любую дату), неделю, месяц, 3/6/12 мес,
  всё время. Объём: общий по всем, по конкретному менеджеру, по конкретной компании
  (и менеджер — по своим компаниям). Листы: «Сводка» + «Заявки».

## Установка
1. Python 3.10+.
2. Бот у **@BotFather** → `BOT_TOKEN`.
3. Свой Telegram ID — у **@userinfobot**.
4. `pip install -r requirements.txt`
5. Запуск:
   ```bash
   export BOT_TOKEN="токен"
   export ADMIN_IDS="123456789,987654321"   # ID всех руководителей через запятую
   export ADMIN_PASSWORD="ваш_пароль"
   export HOME_NAME="KazOC"                  # название вашей головной компании
   python3 main.py
   ```
   Windows (cmd): `set BOT_TOKEN=...` и т.д., затем `python main.py`.

## Переменные окружения
| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен бота (обязательно) | — |
| `ADMIN_IDS` | ID руководителей через запятую | — |
| `ADMIN_PASSWORD` | пароль входа в админку | `1234` |
| `HOME_NAME` | название головной компании | `KazOC` |
| `DB_PATH` | путь к базе | `bot_data.db` |
| `REPORTS_DIR` | папка для Excel | `reports` |

## Круглосуточная работа
Запускайте на сервере/VPS (systemd, screen или tmux). База `bot_data.db` создаётся
автоматически — делайте бэкапы. Старая база обновляется автоматически (миграция колонок).
